# ACES: Agentic E-Commerce Simulator & Choice Analytics

An interactive web-based prototype and econometric simulator based on the research paper **"What Is Your AI Agent Buying? Evaluation, Implications, and Emerging Questions for Agentic E-Commerce"** (Allouah, Besbes, Figueroa, Kanoria, Kumar, 2025; arXiv:2508.02630v2).

---

## Overview

As autonomous AI shopping agents increasingly mediate consumer transactions, online marketplaces face a fundamental shift in demand behavior. This interactive simulator models how frontier Vision-Language Models (VLMs) and headless API agents evaluate product assortments, respond to platform merchandising levers, and react to strategic seller optimizations.

The application is built as a zero-dependency, single-file web application (`index.html`) that runs entirely in the browser.

---

## Core Modules

### 1. Live ACES Sandbox Simulator
Simulates real-time product selection probabilities across an 8-product assortment using the exact Conditional Logit regression coefficients estimated in the paper:
* **Models Supported:** Claude Sonnet 4 (Anthropic), GPT-4.1 (OpenAI), and Gemini 2.5 Flash (Google).
* **System Prompt Strategies:** Default Model Prior, Ignore Position Directive, and Ignore Position + Price Sensitive Directive.
* **Interface Protocols:** Mock-App Visual Grid ($2 \times 4$ VLM layout) and Headless API Feed ($1 \times 8$ ranked JSON list).
* **Product Categories:** Mousepad, Fitness Watch, Office Stapler, and Toothpaste.
* **Interactive Perturbations:** Permute grid positions, randomize promotional badges (`Overall Pick`, `Sponsored`, `Scarcity`), apply exogenous price/rating shocks, or run 500 Monte Carlo position-shuffled trials to compute equilibrium market shares and Herfindahl-Hirschman Index (HHI) concentration metrics.
* **Latent Utility Inspector:** Decomposes individual product utility ($U_{ij}$) into spatial position, badge, price, and rating/review components:

$$U_{ij} = \beta_{\text{pos}}^{\top} x_{ij} + \sum_{\text{tag} \in \mathcal{T}} \beta_{\text{tag}} \mathbb{1}\{\text{tag}_{ij} = 1\} + \beta_{\text{price}} \ln(\text{price}_{ij}) + \beta_{\text{rating}} \cdot \text{rating}_{ij} + \beta_{\text{num-revs}} \ln(\text{num-revs}_{ij}) + \theta_j + \epsilon_{ij}$$

$$P(\text{product } j \text{ chosen in experiment } i) = \frac{\exp(U_{ij})}{\sum_{k=1}^{8} \exp(U_{ik})}$$

### 2. Spatial Position & Badge Bias Explorer
* **Webpage Heatmaps ($2 \times 4$):** Visualizes empirical selection probabilities across identical products, demonstrating that while all models favor Row 1, horizontal column preferences diverge sharply across model families.
* **Headless JSON Heatmaps ($1 \times 8$):** Demonstrates that rank-order biases persist even when visual webpage parsing is removed.
* **Model Upgrade Demand Shock:** Compares Gemini 2.5 Flash Preview against the official Gemini 2.5 Flash release, illustrating how upstream model updates invert spatial biases and reallocate market shares.
* **Price-Equivalence Calculator:** Computes the exact multiplicative price headroom ($\lambda = \exp(-\beta_z \Delta z / \beta_{\text{price}})$) a seller gains or loses from top-row placement, platform endorsements, rating changes, review volume, and sponsored tags.

### 3. Seller Meta-Game & AI Listing Optimizer (AEO)
* **Empirical Case Studies:** Examines single-pass product title optimizations generated by an AI Seller Agent across five product categories (Mousepad, iPhone 16 Pro Cover, Toilet Paper, Office Lamp, and Toothpaste).
* **Causal Market Share Shifts:** Displays pre- and post-intervention selection shares across buyer agents.
* **Interactive Title Lab:** Evaluates custom product titles for front-loaded attribute salience and estimates resulting market share shifts.

### 4. Rationality & Economic Dominance Benchmarks (ACE-RS)
* **Price Dominance Tests:** Evaluates model failure rates when selecting a uniquely discounted item (1%, 5%, 10% discounts, and low/high variance price dispersion) among otherwise identical listings.
* **Rating Dominance Tests:** Evaluates model failure rates when one listing has a higher average star rating (+0.1 rating bump, low variance, and high variance).
* **Instruction Following Tests:** Evaluates adherence to explicit budget, color, and brand constraints.
* **Failure Taxonomy:** Documents empirical chain-of-thought failure modes, including perceptual limitations, dismissal with justification, and unjustified sub-optimality.

## Running Locally

Because the prototype is self-contained in `index.html`, no build step or package manager installation is required.

### Option 1: Direct Browser Execution
1. Download `index.html` to a folder on your computer.
2. Double-click `index.html` to open it in any modern web browser (Chrome, Firefox, Safari, Edge).

### Option 2: Local HTTP Server
If you prefer to serve the application over `localhost`:

```bash
# Using Python 3
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080` in your browser.

---

## Hosting on GitHub Pages

1. Create a new public repository on GitHub (for example, `aces-simulator`).
2. Upload `index.html` and `README.md` to the root of the repository and commit the changes.
3. Navigate to your repository **Settings** > **Pages**.
4. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Wait 60 to 90 seconds for the deployment to complete. Your live application will be available at `https://<your-github-username>.github.io/aces-simulator/`.
